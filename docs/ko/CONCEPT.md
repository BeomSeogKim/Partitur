# Partitur — 개념과 어휘

> 이 문서는 영어 정본 [`docs/CONCEPT.md`](../CONCEPT.md)의 한국어 매핑입니다. 내용이 갈리면 영어 정본이 우선합니다.

## 왜 이 이름인가

**Partitur**는 독일어로 **총보**(總譜)다. 오케스트라에서 모든 악기의 파트가 한 페이지에
세로로 정렬돼 있는 악보이고, 이걸 읽는 사람은 오직 **지휘자** 한 명뿐이다. 연주자는 자기
파트만 본다.

이 프로젝트의 본질이 정확히 그 자리다:

> 각 에이전트(Claude Code, Codex, Gemini, Kimi...)는 자기 파트만 알아도 된다.
> **전체상을 한눈에 쥐고, 각자에게 배역을 나눠주는 유일한 자리** — 그게 Partitur다.

이름을 이렇게 고른 이유는 하나다. 이 프로젝트에서는 이름이 설계를 끌고 간다.
막힐 때마다 던지는 질문이 방향을 정해준다:

> "총보를 쥔 자라면 이걸 어떻게 볼까?"

이 질문은 자연스럽게 아키텍처를 **"중앙의 선언적 계획(score) + 파트 분배"** 구조로 수렴시킨다.
에이전트는 연주자일 뿐, 전체를 아는 건 Partitur다.

## 핵심 역할 네 가지

1. **casts (배역)** — 각 에이전트를 가장 잘하는 파트에 배치한다.
2. **cues (큐)** — 작업을 디스패치하고, 적절한 순간에 진입시킨다.
3. **keeps time (박자)** — 동시성과 파트 간 인계(hand-off)를 조율한다.
4. **holds the score (총보 소유)** — 모든 파트가 파생되는 단 하나의 선언적 계획을 소유한다.

## 어휘 체계

도메인 용어를 통째로 악보에서 빌려온다. 시스템이 커져도 네이밍이 일관되게 유지되도록.

| 용어         | 음악적 의미            | Partitur에서의 의미        |
|--------------|------------------------|----------------------------|
| **score**    | 완성된 총보            | 선언적 계획                |
| **part**     | 한 악기의 성부         | 한 에이전트의 배역         |
| **movement** | 악장 (작품의 한 부분)  | 작업의 단계 / 페이즈       |
| **cue**      | 진입 신호             | 에이전트로의 디스패치      |
| **tutti**    | 전원 합주             | 브로드캐스트 / 팬아웃      |
| **rest**     | 쉼표                  | 유휴 / 대기 중인 에이전트  |
| **tempo**    | 빠르기                | 동시성 & 페이싱            |

## 설계 원칙 (초안)

- 연주자(에이전트)는 교체 가능하다. 총보는 벤더 중립적이다 — Anthropic, OpenAI, Google,
  Moonshot 어느 진영이든 하나의 파트로 들어온다.
- 총보가 진실의 원천(single source of truth)이다. 파트는 총보에서 파생될 뿐, 스스로 전체를
  다시 만들지 않는다.
