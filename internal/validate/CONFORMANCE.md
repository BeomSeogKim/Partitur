# Validate application conformance

The table is closed over the `partitur validate` application and CLI contract.
Each counter-oracle asserts an exact refusal, diagnostic, advisory report, byte
stream, or ordered sequence. The mutation column names the test that becomes
red when the corresponding production check is deleted or inverted.
